# 系统日志与定位参考范围

## 使用入口与排障流程

系统管理 → 系统日志，与记录人员操作的「操作日志」分开。先按最近1小时、24小时或7天查看，也可选择最长31天的时间窗口。

默认显示问题汇总，同一来源、错误类型、接口和异常特征合并，显示出现次数、首次及最近时间、最大与平均耗时。点击问题进入逐条明细，再点击一条查看详情。自动刷新默认关闭，启用后每15秒刷新首页；查看详情、翻页或切到后台时暂停刷新，避免刷屏。

可按严重程度、来源、关键字、请求编号、设备编号、最低耗时筛选。复制错误提示里的请求编号，可关联浏览器错误与同一服务端请求。

详情包括发生时间（毫秒）、处理耗时（毫秒）、HTTP状态、业务错误码、请求路径与方法、请求编号、操作者编号、设备编号（采集点能确定时）、服务版本、异常描述和脱敏堆栈。没有测量的耗时显示「—」，不伪造为0；首次到最近一次是观测窗口，并不代表故障一直未恢复。

## 采集范围

- 服务端：异常抛出、HTTP失败、HTTP200但业务码失败、客户端中断、耗时达到2000ms的普通请求。SSE长连接不按存活时间判为慢请求。
- 浏览器：Vue渲染异常、未处理的异步错误、脚本/资源错误、请求失败和慢请求。浏览器耗时包含网络，与服务端耗时分别展示。
- 设备接入：TCP切帧、解析和处理失败、连接错误。能确认箱号时关联设备。
- 数据库与后台：上报批量写入、地址解析、事件处理异常、启动及未捕获的进程异常。
- 普通成功请求不写诊断日志。日志查询本身不产生成功慢请求日志，避免自循环。

## 权限与数据边界

角色管理中的「系统日志」有两个独立权限：

- `sys:runtime-log:read`：菜单、汇总及脱敏明细。
- `sys:runtime-log:detail`：完整脱敏堆栈与复制，须同时拥有读取权限。

管理员拥有权限，其他角色需明确授权；系统日志是跨组织技术诊断数据，不能仅因有采样箱查看权限而开放。前后端同时校验，直接访问接口也受保护。已登录用户可提交自己的前端诊断，上报者由服务端登录身份确定，不能指定其他操作者或服务版本。

不采集请求正文、请求头、Cookie与URL查询参数。错误文字再次遮蔽密码、令牌、密钥、URL认证信息和长设备标识；消息最长2000字符、堆栈8000字符。自由文本脱敏无法替代人工判断，复制给外部人员前仍需检查业务信息。

## 存储、容量与降级

诊断采用独立SQLite数据库 `server/data/system-logs.sqlite`，可用 `SYSTEM_LOG_PATH` 指定路径，不与业务数据库共用表。业务库故障不影响本地诊断落盘，但业务库无法认证时网页查询也可能不可用，此时从服务器文件与服务日志排障。

默认保留30天或最近100000条，启动及每60秒清理，短暂允许超过条数上限。清理只涉及诊断库；SQLite会复用空闲页，文件不一定立刻缩小。列表每页50条，明细采用时间+ID游标，避免相同毫秒的数据重复翻页。

全服务最多3000条/分钟、每登录用户前端上报30条/分钟；浏览器本身最多20条/分钟并对10秒内同类错误去重。达到限制或写入失败会在页面提示丢弃数量；写入失败不抛回业务链路。丢弃数量是本次进程运行的计数。

## 接口

- `GET /api/v1/system/runtime-logs`：筛选列表与统计；`group=true` 返回问题汇总。
- `GET /api/v1/system/runtime-logs/:id`：有详情权限时返回堆栈。
- `POST /api/v1/system/runtime-logs/client`：已登录浏览器诊断，正文限制32KiB。

请求响应携带 `X-Request-Id`。时间、耗时使用数值毫秒；页面时间按浏览器本地时区显示。查询参数包括 `from/to/level/source/kind/q/requestId/deviceId/minDuration/fingerprint`，明细分页使用 `cursorTime/cursorId`。

## 已知边界

历史故障不会追溯补采。前端未登录、完全离线或诊断上报网络失败时不保证记录，也不本地积压敏感日志。堆栈可能定位到编译后的前端文件，当前没有自动Source Map还原。断电、系统强制杀进程、磁盘故障及内存耗尽不保证能完成最后一次写入；应结合systemd与主机日志。100000条是容量保护配置，不代表已完成十万设备并发压力验证。

## 定位参考范围

采样箱详情的「位置」区增加基站参考范围开关，半径可选100、300、500、1000、3000米，默认500米。点击右侧地点或地图标记后，以该基站坐标画一个随地图比例尺变化的虚线圆；切换地点替换圆，关闭开关或清除选择移除圆，筛掉该地点也会移除。

GPS独立地点不套用基站半径，聚合点的几何中心不画精度圈。基站和GPS重合的地点仅表示其基站记录的参考圈。当前设备没有提供可信精度字段，文案明确「参考范围，非实测精度，不保证设备位于圈内」。该半径是浏览器显示偏好，不下发设备，也不改变上报位置或定位结果。

## 验收记录

- 后端83项自动测试通过，覆盖脱敏、持久化、分组、游标翻页、保留策略、真实HTTP失败/慢请求与关联编号。
- 隔离服务集成验收通过：前端上报、列表与堆栈权限、无权限菜单隐藏、真实404追踪，以及原上报策略生命周期和TCP ACK回归。
- 前端类型检查与生产构建通过；本地以演示数据加载真实组件和天地图SDK，检查日志详情与范围圈交互。演示数据不进入发布包。

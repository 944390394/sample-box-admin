# 网页重新设计：风格、功能拆分、页面和验收

这份文档先定全站的风格，再按「一页只回答一类问题」拆功能，然后给出每个页面的样子，最后写验收机器人怎么查。
改页面时以这里为准；规则变了先改这份文档。

---

## 一、全站风格

### 定位
用的人是调度、采样员、接收方和管理员。他们打开页面最想知道三件事：**箱子现在怎么样、在哪、这个数据可不可信**。
所以风格是「冷静、紧凑、可信」：
- 浅灰底、白卡片，靠留白和细线分区，不用大色块；
- 颜色只有一个主色，其余都是状态色，状态色只用在状态上；
- 数字用等宽数字，对齐好比较；
- **每个会过时的数据都写明是多久以前的**，过时的变灰并标「旧」，不能把旧数据当成现在的。

### 颜色
| 用途 | 浅色 | 说明 |
|---|---|---|
| 主色 | `#165DFF` | 链接、主按钮、选中、进行中 |
| 正常 / 在线 | `#00B42A` | 在线点、电量充足、已到达 |
| 注意 | `#FF7D00` | 电量偏低、箱盖开着、基站定位（误差大） |
| 异常 | `#F53F3F` | 告警、失联、电量过低 |
| 离线 / 过时 | `#86909C` | 离线点、过时数据 |
| 正文 | `#1D2129` / `#4E5969` / `#86909C` | 主要 / 次要 / 辅助文字 |
| 线和底 | `#E5E6EB` / `#F2F3F5` / `#F5F7FA` | 分隔线 / 填充 / 页面底色 |

深色模式用同一套变量名，各自换值（`html.dark`）。

### 字号和间距
- 页面标题 20px 加粗；卡片标题 15px 加粗；正文 14px；表格和信息列表 13px；补充说明 12px。
- 指标数字 24px 加粗、等宽数字。
- 间距按 4 的倍数：4 / 8 / 12 / 16 / 24。页面四周 16px（手机 12px），卡片内边距 16px，卡片之间 12px。
- 圆角：卡片 10px，按钮输入框 6px，标签 4px。
- 卡片平铺、1px 边框；只有能点的卡片悬停时浮起。

### 文字和数字
- 时间：24 小时内写「3 分钟前」，悬停看完整时间；更早的写「11-02 19:25」，跨年写年份。
- 坐标保留 6 位小数，速度保留 1 位，电压用 mV 整数，存储用 MB 两位小数；绝不出现 `4.6999998` 这种数。
- 没有值写「—」；没定位写「未定位」；没权限的整块不显示，并在页面顶部说明一次。
- 不用工程缩写当标题：「HDOP」写成「精度因子」，悬停再解释。

### 数据新鲜度（全站统一）
| 数据 | 新 | 有点旧 | 过时 |
|---|---|---|---|
| 最近上报 | 3 个上报周期内（在线） | — | 超过就算离线 |
| GPS 位置 | 10 分钟内（或 3 个上报周期内，取大的） | 1 小时内 | 超过 1 小时 |
| 基站位置 | 同上 | 同上 | 同上 |

**当前位置怎么选**：GPS 是新的就用 GPS；GPS 过时了、基站比它新，就用基站，同时写「最后一次 GPS 定位是 3 天前」；两个都过时，用较新的那个并标「旧」。
服务端以前只记 GPS 的定位时间，不记基站什么时候更新的，这次补上 `lbsAt`。

### 公共组件
| 组件 | 作用 |
|---|---|
| `PageHeader` | 标题、状态标签、补充信息、右侧操作；详情页下面可以挂一条状态条 |
| `SummaryStrip` | 页头下面的一排关键状态（电量、箱盖、信号、最近上报、位置），切换标签页也一直在 |
| `SectionCard` | 带标题和右侧操作的卡片 |
| `InfoList` | 「名称：值」列表，名称列定宽，编号用等宽字体，可一键复制 |
| `FreshTag` | 「刚刚 / 3 分钟前 / 3 天前」，按新鲜度变色，过时的标「旧」 |
| `LocationLine` | 一行写清位置：来源（GPS / 基站）、地址、多久前、误差 |
| `StatTiles` | 一排指标数字（已有） |

## 二、功能拆分

整站按「一页只回答一类问题」来分：

| 菜单 | 回答什么 |
|---|---|
| 工作台 | 我现在要处理什么；整体有没有异常 |
| 任务单 | 每单进行到哪了；箱子到没到 |
| 采样箱 | 每台箱子现在怎么样、在哪、发生过什么 |
| 实时地图 | 所有箱子现在在哪 |
| 组织管理 | 谁在哪个部门、能做什么 |
| 系统管理 | 系统怎么配置、谁做过什么、系统有没有出错 |

### 采样箱详情（这次重点）
以前「设备信息」把身份、运行、电池、定位挤在一起，而且旧 GPS 和新基站并排摆着，看不出哪个是现在的位置。拆成：

| 位置 | 回答什么 | 内容 |
|---|---|---|
| 页头 + 状态条 | 它现在好不好 | 名称、状态、在线；电量、箱盖、信号、最近上报、**当前位置和多久前** |
| 概览 | 它现在在哪、在干什么 | 位置卡（地图 + 来源 + 多久前 + 旧 GPS 提示）、当前任务、最近事件、电量曲线 |
| 轨迹 | 它去过哪 | 按时间 / 按任务（已有） |
| 事件 | 发生过什么 | 开关箱、上电、充电 |
| 任务 | 参与过哪些任务 | 任务列表 |
| 上报记录 | 原始数据 | 要权限 |
| 设备 | 它是什么、硬件状况 | 身份、归属、运行、电池、定位详情，分成五张卡 |

## 三、页面设计

### 采样箱详情
- 页头：返回、名称、生命周期标签、在线点；下面一行补充信息（IMEI、单位、保管人）；右侧常用操作。
- 状态条：电量（可用百分比，充电中带闪电）、箱盖、信号、最近上报、当前位置（来源 + 多久前，过时变灰）。手机上两列排。
- 概览：左边位置卡占 2/3，右边当前任务和最近事件；下面电量曲线。位置卡头部写「基站 · 深圳市龙岗区… · 2 分钟前」，GPS 过时时下面一行灰字「最后一次 GPS：3 天前（11-02 19:25）· 可能在室内收不到卫星」。
- 设备：五张卡片按网格排（宽屏三列、窄屏一列）：
  - 身份：IMEI、名称、ICCID、IMSI、固件（等宽字体 + 复制）；
  - 归属：单位、保管人、状态；
  - 运行：建档时间、上报周期、最近上电、上次掉电、剩余存储（带进度条）；
  - 电池：可用 / 总电量 / 预留做成一根分段条，下面写学习状态；
  - 定位：GPS 一行、基站一行，各自带来源标签、多久前、坐标、地址、复制；定位细节（速度、航向、海拔、卫星数、精度因子）单独一行，数字取整。

### 采样箱列表
- 「位置」列改用 `LocationLine`：当前位置来源 + 地址 + 多久前，过时的变灰。
- 状态列：在线点 + 生命周期，电量带颜色。

### 实时地图
- 标注颜色：GPS 新的蓝色，基站橙色，过时灰色；点开的侧栏用同一套 `LocationLine`。

### 任务详情
- 箱子列表里的位置同样用 `LocationLine`，写清多久前。

### 其余页面
- 统一用 `PageHeader`、`SectionCard`、新的间距和字号；表格、筛选条、弹窗样式统一。

## 四、验收机器人

`pnpm accept` 一条命令跑完，不碰你的开发库和线上：
1. 在临时目录建一个全新的库，灌入固定的测试数据：几种角色（管理员、调度、采样员、只看任务的接收方），各种状态的箱子（GPS 新、GPS 过时但基站新、只有基站、从没上报、离线、低电、箱盖开着），几张任务单。账号密码每次随机生成，只在机器人进程里用。
2. 用临时端口起一套服务端（只在这套临时环境里关掉验证码）和网页。
3. 用本机 Edge 浏览器按角色登录，逐页检查：
   - 每个菜单页能打开，没有脚本报错和 5xx；
   - 宽屏 1440 和手机 390 宽都没有横向滚动；
   - 采样箱详情：状态条在每个标签页都在；GPS 过时的箱子当前位置显示「基站」，并提示最后一次 GPS 是多久前；设备页没有超过规定位数的小数；
   - 权限：没有「历史轨迹」的角色看不到按时间看轨迹，只能按任务看；没有「给角色分配权限」的人在角色页勾不了权限；
4. 每页截图，生成 `reports/acceptance/latest/index.html`，列出通过和失败；有失败时命令以非零退出。

验收标准就是机器人全部通过，再加上人看一遍截图。

### 怎么跑
```bash
pnpm accept                 # 全部检查，Edge 不显示窗口
pnpm accept -- --headed     # 显示浏览器，看它点
pnpm accept -- --only=采样箱  # 只跑名称里带「采样箱」的检查
```
- 端口：服务端 8100、设备接入 9100、网页 3100，不和开发用的 8000/9000/3000 冲突。
- 验证码只在 `SAMPLE_HOME` + `SAMPLE_ACCEPTANCE=1` 同时设置时才跳过，这两个变量只有机器人会设。
- 检查清单在 `tools/acceptance/checks.mjs`，测试数据在 `tools/acceptance/seed.mjs`。改了页面行为先改清单。

## 五、这一轮做了什么、还差什么

**做了**
- 全站：颜色、字号、间距、圆角统一成上面的规则（`src/styles/theme.scss`、`element-plus-overrides.scss`）；新增 `FreshTag`、`LocationLine`、`InfoList`、`SectionCard` 四个公共组件和 `utils/position.ts`。
- 服务端：基站位置记更新时间（迁移 040 加 `lbs_at`，老数据用最近上报时间补）；当前位置按「基站比 GPS 新 10 分钟以上就用基站」选，**任务的到达判断和开箱录像的到场判断也按这个位置算**，不再拿几天前的 GPS 判断。
- 采样箱详情：页头下加状态条（电量、箱盖、信号、最近上报、位置）；概览的位置卡写清来源和多久前，GPS 过时时地图上灰色标出最后一次 GPS；「设备信息」改名「设备」，分五块，数字取整。
- 采样箱列表、实时地图（列表、标注、侧栏）、任务详情的箱子位置，都用同一套「来源 + 多久前」。
- 系统日志页改用统一页头。
- 逐页重排（第二轮）：
  - 任务单列表：进度改成分步格子 + 状态圆点文字；「我能做」改成「待我处理」小标签；任务号用等宽字。
  - 创建任务单：右侧加「任务摘要」，边填边看；选箱子和核对两步整宽，不显示摘要。
  - 部门：加统一页头和「新增部门」按钮；详情从带边框的表格换成信息格子。
  - 人员：姓名前加头像字；角色拆成一个个小标签。
  - 系统设置：接入信息换成信息列表，地址和端口可以一键复制；分区说明文字统一 13px；手机上左侧导航变成一行横向滑动的标签。
  - 操作日志：统一页头；筛选和表格放进一张卡片，表格去掉满格边框；时间精确到秒，结果用圆点文字。
  - 个人中心：页头显示全部角色；删掉和个人资料重复的「账号概览」「角色权限」「账号状态」三张卡片。
- 验收机器人加到 27 项检查（新增任务单列表、创建任务单摘要、统一页头、人员角色标签、个人中心五项）。天地图外部脚本偶尔加载不完整会抛错，机器人不把这类报错算失败，我们自己代码的报错照样算。

**还差**
- 深色模式没有逐页看过。
- 工作台、角色与权限两页只换了全局样式，没有再逐页调整。
